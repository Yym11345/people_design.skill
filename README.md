# 人生设计教练 · Skill 包

把人生当成一个可以设计、原型验证、反复修订的项目——而不是一道有唯一正确答案的题。

**不诊断，只对话。** 不做测评、不贴标签、不替用户做决定，只陪他走完一轮多轮深度对话，最后产出一份详实的《个人人生设计蓝图》。

## 这个包解决什么

大多数生涯困惑的解法是"想清楚就好了"。但很多时候想不清楚，是因为**问题本身提错了**：

- 有些是**重力问题**——生理条件、时代环境、已经不可逆的既往选择，努力改变不了；
- 有些是**可设计问题**——能被具体行动改变的，靠试就能试出来。

这个技能用四步把"想不清楚"变成"可以开始试"：

1. **你在这里** —— 四个仪表盘（健康/工作/娱乐/爱）各打 0–10 分，定位真实失衡
2. **真问题** —— 把焦虑拆成重力部分与可设计部分
3. **你的指南针** —— 工作观与人生观对齐还是冲突，真北极在哪
4. **三个奥德赛计划** —— 生成三个平权的五年方案（不是主方案加两个退路）
5. **原型行动清单** —— 一个月内能做的一件小事 + 本周就能走的第一步


纯文本实现，**无脚本、无依赖**。

## 使用方式

在 WorkBuddy 对话中直接说：

```
帮我做一次人生设计，我有点迷茫不知道该往哪走
奥德赛计划是什么？带我走一遍并生成三个方案
我该不该换工作？想用人生设计的方法理一理
```

技能会**一次只问一个问题**，根据回答调整追问方向，而不是丢一份问卷给你。

> 完整版蓝图 8000–12000 汉字。如果不特别要求，默认给一个较短版本并主动提出可以扩写。

## 打包

```bash
python build_release.py src/people-design-skill dist
```

产出 `dist/people-design-skill.zip`，可用于 WorkBuddy 开放平台上传。
